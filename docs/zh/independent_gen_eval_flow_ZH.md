# 生成独立内容测评流程图

```mermaid
graph TD
   A[执行生成] --> B[编译构建]
   B --> C{编译构建成功}
   C -->|否| D[直接判定不通过并记录原因]
   C -->|是| E[样例输入验证]
   E --> F{输出正确}
   F -->|否| G[判定不通过并记录原因]
   F -->|是| H[过程指标检查]
   H --> I[难度确认与记录]
   I --> J[最终得分与结果归档]
```

## 具体流程

1. 执行生成：以固定提示运行模型，产出代码结果。
2. 编译构建：直接对生成结果编译或构建；失败则标记不通过并记录原因。
3. 样例输入验证：对给定测试输入运行并比对预期输出；不正确则判定不通过。
4. 过程指标检查：记录并评估响应时间、Token 使用量与成本等指标。
5. 难度确认与记录：按实际完成情况确认或修正难度系数。
6. 最终得分与结果归档：汇总分值与结论并归档证据。
